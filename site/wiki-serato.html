DJ sourcesSerato DJ Pro

Loaded tracks with waveform and beat grid, on the DJ’s computer.

βBeta

Tested with Serato DJ Pro 3.x on macOS with MP3 and AIFF. Windows is expected to work but not tested yet.

How it works

Serato has no live interface for other programs. While it runs, it writes a log that names the file on each deck. LJ Link follows this log and reads title, artist, BPM, key, length, waveform overview, beat grid and cues from the tags Serato writes into the file.

!Warning

That is why LJ Link must run on the same computer as Serato. It does not work over the network.

Step by step

  1. Install LJ Link on the DJ’s laptop and start Serato DJ Pro.

  2. Search automatically. As soon as a track is loaded, its deck appears.

  3. The lighting jockey watches on a tablet or a second computer: open the address shown under the toolbar in the same network. See Serato on the DJ laptop.

Limits

  • No play position: Serato does not reveal it, so there is no moving playhead.
  • Tempo is the track BPM from the file, not the pitched tempo. For the live tempo switch on Ableton Link in Serato (Ableton Link).
  • FLAC and M4A are not read yet. Files without Serato tags show only the file name.
  • No on-air or master information.

💬Something missing or wrong?

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
