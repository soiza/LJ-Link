Use caseOne laptop with onPC

The simplest desk link: everything on one computer.

GearDJ gear, one laptop with LJ Link and grandMA2 or grandMA3 onPC, maybe an MA node or wing
Networkthe laptop in the DJ network; desk address 127.0.0.1
StatusgrandMA2 onPC stable grandMA3 onPC beta

Why this is easy

LJ Link and onPC on the same computer talk over 127.0.0.1 (the computer itself). No address, no firewall between them, no second network. Only the DJ gear has to be reachable.

Steps with grandMA2 onPC

  1. Laptop by cable into the DJ network, Wi-Fi off. LJ Link → Search automatically.

  2. onPC: Setup → Console → Global Settings → Telnet Login Enabled.

  3. LJ Link: LINK → grandMA2 → address 127.0.0.1, port 30000, administrator / admin (or your user) → Save → Send test.

Steps with grandMA3 onPC

  1. onPC: Menu → In & Out → OSC: interface 127.0.0.1 (or the loopback entry), port 8000, Receive Command Yes, prefix empty, Enable Input.

  2. LJ Link: LINK → grandMA3 → 127.0.0.1, 8000 → Save → Send test.

✎Note

If the grandMA3 OSC interface list has no loopback entry, choose the network port the laptop uses and enter that address in LJ Link instead of 127.0.0.1. Not tested yet; please tell us what your onPC shows.

Performance

  • LJ Link needs little CPU, but onPC with a big show and a 3D view needs a lot. Close the browser tab of LJ Link on the laptop if you only watch on a tablet.
  • Laptop on mains power, energy saving off; on Windows choose the *High performance* power plan.
  • An MA node or Art-Net out runs on a second network port, see two networks.

✓Checklist before the doors open

  • Test sent → master shows 120.
  • Effect assigned to that master.
  • Show saved (with the user for LJ Link).

💬Something missing or wrong?

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
