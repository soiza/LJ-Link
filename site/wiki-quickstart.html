StartQuick start

From download to the first waveform in five minutes.

iInfo

This page gets you from download to the first waveform in about five minutes, with the most common setup: Pioneer or Denon gear on one network switch. Other setups are on the network and use case pages.

What you need

  • A computer with macOS 12 or newer or Windows 10/11 (64 bit).
  • DJ gear with Pro DJ Link (Pioneer CDJ/XDJ/DJM) or StageLinQ (Denon Prime, SC6000), or Serato DJ Pro on the same computer.
  • A network switch or a router and network cables. Many DJM mixers have LINK sockets that work as a small switch.
  • Optional: a light desk (grandMA2, grandMA3, Wolfmix, Daslight, OSC program) for the tempo.

Five steps

  1. Install. Download the installer from the download section and open it. On the first start macOS and Windows warn once because the app is not signed yet: how to open it anyway.

  2. Allow the network. macOS asks for the local network: allow it. Windows asks the firewall: tick private networks and allow. Without this LJ Link finds nothing.

  3. Connect by cable. Players, mixer and computer to the same switch. Switch Wi-Fi off on the computer. Give each player its own number (1, 2, 3 …).

  4. Search. Start LJ Link, the interface opens. Press Search automatically. Pioneer, Denon, Serato and Ableton Link are found at the same time, devices that come later are added by themselves.

  5. Load a track. Pioneer: from a USB stick or SD card exported with rekordbox. Denon: from the device’s Engine library. The waveform appears.

Next steps

  • Send the tempo to the desk: light desks.
  • Open the same view on a tablet: waveforms on a tablet.
  • Nothing found? Troubleshooting.
