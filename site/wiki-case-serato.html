Use caseSerato on the DJ laptop

When the DJ brings a laptop instead of a USB stick.

GearDJ laptop with Serato DJ Pro, a tablet or laptop for the LJ
NetworkDJ laptop and tablet in the same Wi-Fi or router
StatusBeta

Talk to the DJ first

LJ Link has to run on the DJ’s laptop, because it reads Serato’s log there. Ask before you install anything on someone else’s computer. LJ Link only reads; it does not change Serato or the files.

Steps

  1. Install LJ Link on the DJ laptop, start it, Search automatically.

  2. Load a track in Serato: the deck appears with waveform overview, beat grid and cues.

  3. Optional for the live tempo: in Serato Setup → Expansion Packs → Ableton Link on, and the Link button on.

  4. Laptop and tablet in the same network. On the tablet open the address shown under the toolbar, for example http://192.168.1.50:8080.

  5. Tempo to the desk: LINK on the DJ laptop, the desk must be reachable from there. Under SEND BPM choose the Ableton Link deck for the pitched tempo.

iInfo

Serato decks have no playhead: you see what is loaded and its waveform, but not where the track is. Count with the beat grid and the tempo.

Limits

  • MP3 and AIFF tested; FLAC and M4A not read yet.
  • Tested on macOS. Windows not tested yet.
  • Hotel or venue Wi-Fi often isolates devices: use your own travel router.

💬Something missing or wrong?

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
