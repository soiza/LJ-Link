Light desks · stablegrandMA2 and onPC

The tempo on a speed master over Telnet.

✓Status

Stable: search, Telnet login and SpecialMaster 3.16 At {bpm} were tested on a real grandMA2 onPC. A hardware console uses the same software and is expected to behave the same; not tested yet.

How it works

The grandMA2 has no OSC input. LJ Link connects like a Telnet program to the command line of the desk (TCP port 30000), logs in as a user of the show and types the command for the speed master.

1. Switch on Telnet

  1. On the desk (or in onPC) press Setup.

  2. Tap Console, then Global Settings.

  3. Set Telnet to Login Enabled.

While Telnet is off, the search still finds the desk, but it takes no commands.

2. A user for LJ Link

Every Telnet connection logs in as a user of the show. Names and passwords are case sensitive.

OptionUser / passwordNote
default of every showadministrator / adminLJ Link enters this by default; full access
own user (recommended by MA)e.g. lj / linkrights at least *Playback*, if unsure *Program*; save the show

!Warning

The default password admin is public. In shows on an open network change it, and enter the new one in LJ Link.

3. Prepare the speed master

  1. Choose the speed master: Speed 1 to 15 or Speed 16 = BPM. On the command line they are SpecialMaster 3.1 to SpecialMaster 3.16.

  2. Assign the effects and chasers that should run in time to this master.

  3. Test by hand: type SpecialMaster 3.16 At 120 and Enter. The master shows 120 BPM in the *Masters* window and the effect runs in time.

4. Set up in LJ Link

  1. Menu (☰) → Light desk link or tab LINK → grandMA2 / grandMA2 onPC (Telnet).

  2. Search for the desk and click the hit. It finds every grandMA2 and onPC in the network, even with Telnet off. Or type the address; onPC on this computer: 127.0.0.1.

  3. Port 30000. User and password as in step 2.

  4. Send to speed master: Speed 16 (BPM) or 1 to 15. The command becomes SpecialMaster 3.16 At {bpm}.

  5. Save, Send test (120 BPM). The master jumps to 120.

iInfo

{bpm} becomes a whole number such as 128: the grandMA2 command line ignores decimals (At 128.0 does nothing). Every command lands in the command history, hence the repeat only every 15 seconds.

✎Note

Do not enter Fixture Setup or the schedule over Telnet: according to MA this locks other users out without warning. LJ Link only sends the command you entered.

▶Help us test

Tried it on your desk? Post the result in our Discord or report it: desk, software version, what worked and what did not. That is how beta and alpha become stable.

💬Something missing or wrong?

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
