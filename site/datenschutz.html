Auf dem Server läuft der LJ Link Bot auf einem eigenen Server von uns. Er liest neue Nachrichten in den Kanälen Helpdesk, Support und Installation, vergleicht sie mit dem öffentlichen Wiki und antwortet mit passenden Wiki-Links. Gespeichert werden nur die Kennungen der Helpdesk-Beiträge, auf die er schon geantwortet hat (damit er nicht doppelt antwortet), und die bereits angekündigten Versionen. Außerdem veröffentlicht der Bot Hinweise auf neue Versionen; dazu fragt er die öffentliche Schnittstelle von GitHub ab. Möchtest du keine automatischen Antworten, sag einem Moderator Bescheid.

Privacy

This website uses no cookies, tracking or analytics. It is hosted on GitHub Pages; GitHub processes technically necessary access data such as your IP address. To show the current version, your browser asks the public GitHub API (api.github.com), which also receives your IP address; we receive nothing. Your language choice is stored only in your browser. On our Discord server, Discord Inc. (USA) processes your data under its own privacy policy; we see your username, roles and messages there. The LJ Link Bot reads new messages in the helpdesk and support channels to reply with wiki links; it does not store message content, shares nothing and uses no AI. The LJ Link program sends no usage data; only its update check asks GitHub for a new version. Controller: Philipp Spruck, NEXTPHILM, address and email as above.
