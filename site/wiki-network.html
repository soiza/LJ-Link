NetworkNetwork basics

What you need to know so that LJ Link finds every device.

✓Tip

Short version: everything on one switch or router by cable, Wi-Fi off on the computer, every player its own number. That works almost always. The rest of this page explains why, so you can fix it when it does not.

Why the network matters

DJ players do not wait to be asked. They announce themselves several times a second on the network (broadcast) and send their status, beats and position the same way. LJ Link listens to these packets. That is why you cannot simply type in a player’s address: LJ Link has to be in the same network to hear it.

Broadcasts do not cross a router into another network and get lost easily over Wi-Fi. Hence the three rules below.

The three rules

  1. One network. Computer, players and mixer hang on the same switch or router, or on switches connected to each other.

  2. One connection. The computer uses only one connection into this network. Wi-Fi and cable in the same network at once means every packet arrives twice.

  3. Same address range. All devices need addresses from the same range, for example all 192.168.1.x or all 169.254.x.x.

IP addresses in one minute

Every device in a network has an address such as 192.168.1.20. With the usual subnet mask 255.255.255.0 the first three numbers name the network and must be equal; the last number names the device and must differ.

ComputerDeviceResult
192.168.1.10192.168.1.50same network
192.168.1.10192.168.0.50different network
169.254.12.7169.254.201.3same network (mask 255.255.0.0)
169.254.12.7192.168.1.50different network

Where the addresses come from

  • With a router (DHCP): the router hands out addresses like 192.168.1.x. Nothing to set up.
  • Without a router (only a switch or a direct cable): every device gives itself an address 169.254.x.x after a short while (self-assigned, also called link-local). Players, Mac and Windows all do this, so they find each other.
  • Fixed by hand: needed when a device has a fixed address, for example many light desks. See set an IP address.

!Warning

Self-assigned addresses take a moment. After plugging in, wait up to a minute before you search. If a router comes into the network later, devices may keep their old 169.254 address: then restart the players or plug their cable out and in.
