NetworkSet an IP address

Only needed in a few cases. Here is how, step by step.

When you need this

  • The light desk has a fixed address and the computer is in another range.
  • Set up manually in LJ Link says the computer and the device are in different networks.
  • The players have 169.254.x.x and the computer has a router address, or the other way round.

Normally you do not need it: with a router everything is automatic, and without one the devices give themselves fitting addresses.

Find the addresses

DeviceWhere
Pioneer playerMenu → Utility → Link Info (on some models *Network Info*)
Denon Prime / SCSettings → network or *About*
grandMA2Setup → Network → Network Interface, onPC in the title bar
grandMA3Menu → Network, under *Interfaces*
this computerLJ Link → Set up manually lists all network adapters with their address

macOS

  1. System Settings → Network → choose the cable connection (Ethernet or the USB adapter) → Details.

  2. TCP/IP → *Configure IPv4*: Manually.

  3. IP address: same first three numbers as the desk, own last number. Example desk 192.168.0.10 → computer 192.168.0.20.

  4. Subnet mask 255.255.255.0. Router: leave empty. OK.

Windows

  1. Settings → Network & Internet → Ethernet → your connection.

  2. At IP assignment press Edit → Manual → switch on IPv4.

  3. IP address as above, subnet mask 255.255.255.0, gateway and DNS empty. Save.

!Warning

Write down what was set before and change it back after the gig. A computer with a fixed address gets no internet at home.

Players and a fixed address

Pioneer players with 169.254.x.x only talk to a computer in the same range. If you give the computer a fixed 192.168.x.x address on the same cable, it can no longer hear them. Use a second network port for the desk (setup F) or a router for all.

Check with LJ Link

On the start screen Set up manually → choose the device → enter its address → Check connection. You get a tick or a cross for each step (valid address, network connection, same network, device answers, data interface) and a sentence what to change.

💬Something missing or wrong?

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
