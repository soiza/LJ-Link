Light desks · betagrandMA3 and onPC

The tempo on a speed master over OSC.

βBeta

Built from the grandMA3 manual (OSC /cmd, Master 3.1 At BPM) and tested against a simulation. Not yet confirmed on a real grandMA3 or onPC.

How it works

The grandMA3 takes command line commands over OSC (address /cmd, text). LJ Link sends the command for the speed master there.

1. OSC input on the desk

  1. Menu → In & Out → tab OSC.

  2. At Interface choose the network port through which the LJ Link computer is reachable.

  3. Add a line (or use one) with these values:

    FieldValue
    ModeUDP
    Port8000 or another free port, the same in LJ Link
    Prefixempty
    Receive CommandYes (otherwise commands are ignored)
    EchoInputYes for testing: incoming messages show in the System Monitor

  4. Switch on Enable Input. When OSC arrives, its title bar lights yellow.

iInfo

With a prefix such as gma3 the desk expects /gma3/cmd. LJ Link sends to /cmd, so leave the prefix empty.

2. Speed master

  1. Assign the effect or sequence to a speed master (the first is Master 3.1).

  2. Test on the command line: Master 3.1 At BPM 120, Enter.

3. Set up in LJ Link

  1. Light desk link → grandMA3 / grandMA3 onPC (OSC).

  2. Address of the desk (onPC on this computer: 127.0.0.1). The search does not find a grandMA3 yet.

  3. Port as on the desk, e.g. 8000. Command Master 3.1 At BPM {bpm}.

  4. Save, Send test. With EchoInput the message shows in the System Monitor.
