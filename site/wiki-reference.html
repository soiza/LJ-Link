Command line

Start options for experts and scripts:

OptionEffect
--port Nweb interface on port N instead of 8080
--privacystart in privacy mode
--no-browserdo not open the interface at start
--no-trayno icon in the menu bar or next to the clock
--helplist all options

Files

FileContent
~/.ljlinkpro/settings.jsonprivacy mode, language
~/.ljlinkpro/link.jsonlight desk link settings

~ is your user folder. Deleting the folder resets LJ Link. View settings (zoom, colours) are stored in each browser.
