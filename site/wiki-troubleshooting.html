Light desk

The desk does not react
CauseFix
grandMA2: Telnet offSetup → Console → Global Settings → Telnet: Login Enabled
grandMA2: Error #44user needs more rights
grandMA3: Receive Command off, prefix setReceive Command Yes, prefix empty, Enable Input
ChamSys MagicQ: no reaction (alpha)OSC Mode Rx and the same port on the desk, an Autom row of type OSC Message with exactly the address from LJ Link; see ChamSys MagicQ
effect not on that speed masterassign it
desk in another networknetwork setups
tempo jumps between two valuesSEND BPM on one deck; see Tempo on the light desk jumps
Tempo on the light desk jumps (137.9, 138.0, 137.9 …)

Cause: the player stands right at a rounding edge, for example 137.95 BPM. LJ Link sends the tempo rounded to 0.1 BPM, and tiny swings of a few hundredths flipped the value between 137.9 and 138.0. A Wolfmix can restart its beat on every change.

What LJ Link does (1.7.4 and newer): it steadies the raw tempo first and only sends a new value when it moves more than 0.15 BPM away from the sent one. So the tempo stays put at the rounding edge. A change of 0.25 BPM or more goes through in under a second; smaller deviations of up to 0.15 BPM are deliberately not sent. Since 1.7.5 the BPM on the deck shows the real value of the player with two decimals (137.95); the sent, steadied tempo is the tooltip on the BPM field. The display change is not tested on real hardware yet.

Recommended: update to the newest version, put SEND BPM on one deck, and where the desk can take it use Ableton Link (for example Wolfmix or Daslight).

Still jumping? Please send a report while it happens. The diagnostic data show the raw tempo of every Pioneer player, so we can see where the jumps come from.

Report a problem

  1. Keep LJ Link open while the problem is there, gear connected.

  2. Menu (☰) → Report a problem, or in the menu of the icon.

  3. Describe gear, firmware, Mac or Windows and what you see. Leave Include diagnostic data ticked: version, adapters, devices and their state, what each deck receives, last log lines. No titles, covers or passwords. Show diagnostic data shows it before sending.

  4. Send by email (to fehlermelden@nextphilm.de) or Report on GitHub. Or ask on Discord.

💬Something missing or wrong?

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
