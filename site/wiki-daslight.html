Light desks · testedDaslight

Ableton Link (recommended) or a tap on every beat.

✓Status

Tested with Daslight, both ways. Ableton Link is the recommended way: Daslight gets the tempo, the beat and the bar and follows at once. The OSC tap works too, but Daslight has to measure the tempo from the taps, so it needs a few beats after every change.

WayWhat Daslight gets
**Ableton Link**tempo, beats and bars, exactRecommended
**OSC tap**a tap on every beat for BPM Tap; Daslight measures the tempoWorks

Daslight cannot take the tempo as a plain OSC number, so the old way (a number at /ljlinkpro/bpm) does not work.

Ableton Link (recommended)

  1. In LJ Link: Menu (☰) → Light desk link → Daslight (Ableton Link) – recommended. That is all: it switches on Ableton Link further down in the menu if it is off.

  2. In Daslight: Settings → MIDI / Audio / BPM → BPM SOURCE → Ableton Link Sync.

  3. Under SEND BPM choose the deck (or Auto). The BPM in Daslight follows it.

✎Note

Both computers must be in the same network (or it is the same computer). Link uses UDP port 20808; a firewall must let it through. More on Ableton Link.

OSC tap

On every beat of the SEND BPM deck LJ Link sends an OSC message, first with the value 255 (button pressed), a few milliseconds later with 0 (released). In Daslight you map it to BPM Tap.

  1. In Daslight: Settings → OSC → tick OSC Input and note the Incoming Port (default 7000). The IP address of the Daslight computer is shown at the top.

  2. In LJ Link: Light desk link → Daslight (OSC tap), the IP address of the Daslight computer, port 7000, address /ljlink/tap. Save.

  3. In Daslight open the OSC mappings, click the BPM tap button (the hand next to the BPM) and press Send test in LJ Link. Daslight learns the address.

  4. The mapping shows BPM Tap · Global · /ljlink/tap. Close the window; the BPM now follows the taps.

Good to know

  • The tempo is only as exact as Daslight's tap averaging; after a tempo change it takes a few beats.
  • To try it without DJ gear: under SEND BPM choose the fixed value and type a tempo, or start the demo and tick Send demo data.
  • Nothing arrives? Check the IP address and port, the firewall on the Daslight computer, and that OSC Input is ticked.
