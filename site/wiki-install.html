StartInstall and update

macOS and Windows, with the warnings on the first start and the permissions LJ Link needs.

Which file

ComputerFile
Mac with Apple chip (M1 and newer)LJ-Link-PRO-macos-arm64.dmg
Mac with Intel processorLJ-Link-PRO-macos-intel.dmg
Windows 10 / 11, 64 bitLJ-Link-PRO-windows.exe

Java is included, nothing else needs to be installed. Not sure which Mac you have? Apple menu → About This Mac: “Chip Apple M…” means Apple chip, “Processor Intel” means Intel.

macOS

  1. Open the .dmg and drag LJ Link into Applications.

  2. Start LJ Link once. macOS says *“LJ Link” Not Opened*: press Done (not *Move to Trash*).

  3. Open System Settings → Privacy & Security and scroll down.

  4. At *“LJ Link” was blocked* press Open Anyway and confirm with password or Touch ID, then Open once more.

  5. macOS asks about the local network: Allow. Without it no player is found.

✎Note

Missed the network question? System Settings → Privacy & Security → Local Network → switch LJ Link on.

For experts, this removes the warning for good:

xattr -dr com.apple.quarantine "/Applications/LJ Link.app"

Windows

  1. Start LJ-Link-PRO-windows.exe. In the blue SmartScreen window press More info, then Run anyway.

  2. Click through the installer.

  3. On the first start the firewall asks: tick Private networks and press Allow access.

!Warning

If Windows calls your network Public, the firewall blocks LJ Link even after you allowed it for private networks. Settings → Network & Internet → your connection → network profile Private.

Missed the firewall question? Windows Security → Firewall & network protection → Allow an app through firewall → tick LJ Link for *Private*.

Where LJ Link lives

After the start an icon appears in the menu bar (Mac, top right) or next to the clock (Windows, bottom right, maybe behind the arrow). Its menu opens the interface, switches the privacy mode, checks for updates, reports a problem and quits.

A second start does not run LJ Link twice: it only opens the interface of the running one.

Updates

At start LJ Link checks once whether a new version exists and tells you. Check for updates in the menu of the icon downloads and installs it: on a Mac the app is replaced and restarts, on Windows the installer opens. Settings stay.

✓Tip

The check needs the internet. In a show network without internet it just says it could not reach GitHub; everything else works as usual. Update at home, not at the gig.

✎Note

Versions 1.2.x cannot update themselves (“Handshake failed”). Install the newest version once by hand.

💬Something missing or wrong?

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
