Programs that take the same ports

A port can only be used by one program on a computer. Close these programs on the computer that runs LJ Link:

ProgramConflictWhat you see
rekordbox (Link or Performance mode)UDP 50000–50002players not found or no tracks
Beat Link Trigger, SoundSwitch, a second LJ LinkUDP 50001yellow note *Beat port 50001 is in use*
Engine DJ, SoundSwitch, Resolume (StageLinQ)UDP 51337Denon not found or reconnecting
another web server on 8080TCP 8080interface does not open

✎Note

On another computer in the same network these programs do not disturb LJ Link’s ports.

Firewall

macOS

macOS asks once for Local Network. Allow it. Changing later: System Settings → Privacy & Security → Local Network. If the macOS firewall is on (Network → Firewall), allow incoming connections for LJ Link.

Windows

Allow LJ Link for private networks and make sure the network profile is *Private*, not *Public*. Other security software (antivirus with firewall) may need its own rule for LJ Link.

Light desk computer

grandMA onPC on another Windows computer also asks the firewall on its first start: allow private networks there too, otherwise the tempo never arrives.

VPN and virtual adapters

VPN clients, Parallels, VMware, VirtualBox, Hyper-V and Docker add virtual network adapters. They can make LJ Link listen in the wrong place or see packets twice. Switch them off for the gig.

💬Something missing or wrong?

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
