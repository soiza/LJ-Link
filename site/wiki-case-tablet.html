Use caseWaveforms on a tablet

See the drops coming, wherever you stand.

GearDJ gear, a computer with LJ Link, a tablet, phone or second laptop
Networkrouter with Wi-Fi, or an access point on the switch
StatusStable

Steps

  1. Computer with LJ Link by cable in the DJ network, as on setups compared.

  2. Wi-Fi for the tablet: a router or access point connected to the same switch. Not the guest network.

  3. Under the toolbar LJ Link shows its address, for example http://192.168.1.50:8080. Open it in the tablet’s browser.

  4. Full screen and night mode on the tablet. Add it to the home screen for one tap next time.

!Warning

If the computer only has 169.254.x.x addresses (no router), LJ Link shows no address for tablets: then there is no network a tablet could join. Add a router or access point.

What a tablet can do

  • See everything: waveforms, decks, mixer, SEND BPM mark.
  • Own view settings: zoom, view, colours, day or night, language.
  • Not: start or stop LJ Link, change SEND BPM or the privacy mode. That stays on the computer.
