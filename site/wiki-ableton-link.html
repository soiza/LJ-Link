DJ sourcesAbleton Link

Take the tempo from Link, or give Link the DJ’s tempo and beat.

What it is

Ableton Link keeps the tempo and the beat of several programs in step over the network. Serato DJ Pro, Traktor, Ableton Live, Resolume, Daslight and many apps support it. LJ Link uses it in both directions:

DirectionWhat happensStatus
**Receive**LJ Link listens to the session and shows its tempo as a deck, for the light deskBeta
**Send**LJ Link joins the session and gives it the tempo, beats and bars of a DJ deckTested

Receive: the tempo of a Link session

βBeta

Built from Ableton’s published protocol and tested against it, but not yet tried with a real session at a gig.

LJ Link listens to the session and takes its tempo. Receiving alone never joins or changes the session.

When to use it

  • Traktor or another program without its own support: tempo to the light desk.
  • Serato: the live tempo with pitch, in addition to the track data from the file.
  • Live sets with Ableton Live.

Step by step

  1. In the DJ software switch on Link (Serato: *Setup → Expansion Packs → Ableton Link*, Traktor: *Preferences → Link*, Live: *Link* button).

  2. LJ Link runs on the same computer or in the same network.

  3. Search automatically. A deck *Ableton Link* appears with the session tempo.

  4. Under SEND BPM choose this deck, if the tempo should come from Link.

Limits

  • Tempo only: no track, no waveform, no position.
  • The beat phase is not read yet, so a Wolfmix gets free running beats at this tempo.
  • rekordbox may only follow a Link session and not lead it; then it gives no tempo.

Send: lead the Link session with the DJ tempo

✓Status

Tested with Daslight (BPM source *Ableton Link Sync*): the tempo follows the SEND BPM deck at once and stays in step. Before that it was checked against Ableton’s own Link library on one computer, with the beat about 1 ms off the deck. Ableton Live, Resolume and other Link programs use the same protocol; if one of them behaves differently, please tell us.

LJ Link takes part in the Link session like any other program and gives it the tempo of the deck chosen under SEND BPM. Every program with Link in the network then runs at the DJ’s tempo: visuals in Resolume, a backing track in Ableton Live, a light program with Link, an app on a phone. With beats and bars switched on, their beat and the start of their bar also sit on the beat grid of the deck.

When to use it

  • Pioneer or Denon players and a program that speaks Link but not Pro DJ Link or StageLinQ (Resolume, Ableton Live, Daslight, apps).
  • A light program with Link instead of OSC: it gets the tempo and the beat, not only a number.
  • Several programs at once: one switch in LJ Link, every Link program follows.

Step by step

  1. Connect the DJ gear and search as usual, so the decks show up.

  2. Menu (☰) → section Ableton Link → tick Lead the Link session with the DJ tempo.

  3. Leave Also align beats and bars to the deck ticked if the other programs should be on the beat, not only at the tempo.

  4. In the other program switch Link on (Live: *Link* button top left; Resolume: *Preferences → Ableton Link*).

  5. Below the switches LJ Link shows the session: tempo and how many other programs are in it. The leading deck wears a white LINK.

✓Tip

LJ Link and the other program must be in the same network, or on the same computer. Link uses UDP port 20808 (multicast 224.76.78.75); a firewall must let it through, see ports.

What is sent

SentComes from
TempoYesthe pitched tempo of the SEND BPM deck, Pioneer, Denon and Serato
Beat and barYes, optionalbeat grid and position of the deck: Pioneer and Denon only, Serato has no position
Start / stopNodeliberately not: a DJ pausing a deck would stop Ableton Live
Track, waveformNoLink has no place for them

How it behaves

  • A Link session that is already running is joined, a new one is started if there is none. LJ Link then sets its tempo.
  • LJ Link leads: if someone changes the tempo in another program, LJ Link sets it back to the deck at once. Switch it off to lead from elsewhere.
  • The beat is corrected when it is more than 8 ms off the deck, at most every 0.3 seconds, so cues and loops on the player are followed quickly.
  • No deck with a tempo (nothing loaded, all stopped): the session keeps its last tempo.
  • The demo leads the session only with Send demo data ticked (light desk settings). The fixed value under SEND BPM leads it with the tempo you type in, handy for tests.
  • If SEND BPM is set to the *Ableton Link* deck itself, LJ Link does not send, otherwise it would only send the session back to itself.

Status messages

MessageMeaning
“Session: 128.00 BPM, 1 other program”works: the tempo of the session and how many programs follow
“… 0 other programs”no other program in the session: is Link on there, same network, firewall?
“No deck with a tempo: the Link session keeps its tempo.”nothing to lead with; load a track
“SEND BPM takes the Link session itself …”choose a DJ deck or Auto under SEND BPM
“Demo mode: the Link session is not led.”connect real gear, tick Send demo data, or choose the fixed value under SEND BPM

Known limits

  • Older Pioneer players (CDJ-2000NXS2 and before) report their position only between beats; the beat may then wobble more than with a CDJ-3000.
  • Two programs that both want to lead (say Traktor as Link master and LJ Link) pull the tempo back and forth. Let only one lead.

▶Help us test

Tried it? Post the result in our Discord or report it: which players, which Link program, whether tempo and beat stayed in step. That helps other users.

💬Something missing or wrong?

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
