Use caseTwo networks

One computer between the DJ network and the light network.

GearDJ network, a separate light network (MA-Net, Art-Net, sACN), a computer with two network ports
Whylight networks often have fixed addresses and lots of traffic; they should stay apart
StatusWorks, depends on your computer

Steps

  1. Port 1 (built-in or adapter 1) into the DJ switch. Leave it automatic.

  2. Port 2 (USB network adapter) into the light network. Give it a fixed address in the light network’s range, for example desk 2.0.0.1 → computer 2.0.0.50, mask 255.0.0.0 or as the light network uses. How to

  3. Never a gateway on port 2. Leave *router* empty, so internet and DJ traffic do not go there.

  4. LJ Link → Search automatically. It picks the DJ port by itself from where the players are. *Set up manually* lists both ports.

  5. LINK → desk address in the light network (2.0.0.1). The computer sends it through port 2 because that network is directly on it.

✕Important

The two networks must use different address ranges. If both are 192.168.1.x, the computer does not know where to send and both break.

Why not one network

  • Art-Net and sACN can send a lot of broadcast traffic; DJ gear does not need it.
  • The light network is often installed with fixed addresses you should not change.
  • A problem in one network does not take the other one down.

✓Checklist before the doors open

  • Two different address ranges.
  • No gateway on the light port.
  • Test sent arrives on the desk.

💬Something missing or wrong?

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
